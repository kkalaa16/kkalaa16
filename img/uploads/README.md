# Image drop folder

Drop new project images here (via GitHub's web UI upload, or hand them to
Claude directly) and they'll get wired into the matching highlight plate,
archive card, or cluster-diagram tooltip.

To make an image easy to place correctly, name it with the project's id as
a prefix, e.g. `bwb-concept-render.png`, `hyperloop-pod-photo.jpg`. Current
project ids: doosan, ibrido, afrl, tue, thesis, hyperloop, telemetry-ml,
mfg, gas-turbine, option-pricing, trajectory, boeing, bwb, iit, fsi, tcnj,
cabs, vawt, scramjet, gta, hal, ccs.

If you're not sure which id a project maps to, just say which project in
the message and skip the naming convention -- this file is a landing spot,
not a hard requirement.
